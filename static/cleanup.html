원본정리 후
A얼굴 클로즈업(ECU)에 얼룩이 보일 때

얼굴이 크게 나오면 이목구비가 거의 바뀌지 않습니다. 마스크 없이 전체로 돌려도 됩니다.

  1. 마스크는 칠하지 않고 그대로 둠
  2. 정리 시작
B인물이 작게 나온 컷

작은 얼굴은 다시 그려지면서 변형됩니다. 얼굴(또는 인물 전체)을 마스크로 잡고 반전해서, 그 부분을 뺀 나머지만 정리합니다.

  1. 자동 선택에 face 혹은 character → 마스크에 추가
  2. 잡힌 영역 중 얼룩이 있어 정리할 부분은 지우개(E)로 지움
  3. 마스크 반전(I) — 잡은 부분을 뺀 전부가 분홍색이 됨
  4. 정리 시작
C특정 부분만 정리하고 싶을 때

머리카락처럼 얼룩이 몰린 곳만 정리하고 나머지는 그대로 둡니다.

  1. 자동 선택에 hair 같은 단어 → 마스크에 추가 (또는 브러시로 직접 칠하기)
  2. 필요 없이 잡힌 곳(앞쪽 흐린 인물, 장신구 등)은 지우개로 지움
  3. 정리 시작

공통: 강도는 0.18부터 시작하고, 결과는 2~4장 뽑아서 고르는 것을 권장합니다. 끝나면 내 작업 → 비교, C로 원본·결과·스플릿을 바꿔 가며 확인합니다.

  • 칠한 곳은 다시 그려짐작게 나온 얼굴 · 손 · 글자 · 장신구는 마스크에서 빼야 합니다.
  • 작은 물체는 형상이 무너집니다.유지해야 하는 물체라면 해당 부분은 마스크를 적용하세요.
  • 결과가 매번 조금씩 다름여러 장 뽑아서 고르는 것을 권장합니다.
  • 항상 원본에서 시작함여러 부위는 한 마스크에 같이 칠해야 합니다.
